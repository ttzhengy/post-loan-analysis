# 决策动作库（decision-actions）

被 `scripts/attribution.py` 引用。按「贡献度 × 可干预性」四象限输出管理动作，对齐《报告模板.doc》三(3)管理策略要求（每主题 1–2 项策略，含适用对象/动作机制/执行条件/代价例外/预期效果/验证安排）。

## 一、四象限定位

| 坐标         | 象限       | 决策基调            |
| ---------- | -------- | --------------- |
| 高贡献 + 高可干预 | **立即整改** | 定人定时定 KPI，管理层督办 |
| 高贡献 + 低可干预 | **组合对冲** | 限额、分散、定价补偿      |
| 低贡献 + 高可干预 | **例行优化** | 纳入常规流程改进        |
| 低贡献 + 低可干预 | **记录监控** | 只跟踪不投入          |

**判定阈值**：贡献度高 = 不良余额贡献占比 ≥10% 或进入帕累托 Top-N；可干预性高 = 存在明确责任岗 + 可执行动作 + 6 个月内见效。

## 三、动作 6 字段

```json
{
  "action_id": "A-001",
  "quadrant": "立即整改",
  "action": "对零散行政村客户补充村两委交叉验证，尽调覆盖率100%",
  "owner": "{{待补：责任岗}}",
  "deadline": "2026-12-31",
  "kpi": "零散村客户尽调覆盖率",
  "baseline": "当前 X%",
  "target": "100%"
}
```

缺任一项 → `incomplete: true`，不进 summary Top3。

## 四、验证指标设计原则

1. **可计量**：覆盖率/完成率/金额/天数，不是「有所改善」
2. **有基线**：给当前值
3. **有时限**：绑定日期
4. **可归因**：避免用受核销影响的总不良率，改用分组不良率/新发生逾期率
5. **可取证**：说清验证材料（影像、系统日志、报表）

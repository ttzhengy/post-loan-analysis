# 归因方法论（attribution-methodology）

被 `SKILL.md` 与 `scripts/attribution.py` 引用。沉淀自《归因方法论.txt》《10个主题.txt》的思考过程，回答：**为什么发生 → 造成多少损失 → 管理层该做什么**。

## 一、核心原则：归因是"讲故事"，不是"列统计"

一份归因报告最容易犯的错，不是算错数，而是算对了数但讲错了故事。
- 数字正确 ≠ 归因正确：98.6% 损失归因"治理缺陷"没错，但压住了底下"经营恶化"的叠加成分。
- 精度与解释力是矛盾的：每笔都精确归类 → 丢掉多因叠加；全列出来 → 没有决策价值。
- **报告第一屏必须是"现象 + 成因链"**，不是统计表格、不是综合得分、不是 Top N 排行。

### 1.1 准入 vs 存量是两种场景

| | 贷前准入 | 贷后存量管理 |
|---|---|---|
| 要回答 | 这笔钱能不能放 | 已经放的为什么变坏 |
| 输出 | 一个判断（yes/no） | 一套动作（改哪个环节） |
| 评分够不够 | 够 | **不够**（需要知道先修哪块） |

### 1.2 评分只放附录

综合得分（或 Top N 排行）定位为"横向可比标尺"，放附录。主报告第一屏是根因链——读报告的人第一眼看到"钱是怎么丢的"，不是"多少分/谁排第一"。

## 二、三层分析工具：帕累托 → 鱼骨 → 5Why

- **帕累托**解决成本与聚焦：幂律分布真实存在，锁 80% 累计贡献，把对象从上万条压到个位数。
- **鱼骨六维**解决"没想到"：强制把借款人/产品/担保/流程/环境/监控都过一遍，避免只盯一个方向。
- **5Why** 解决"停在表面"：追到"应收账款逾期"是现象，追到"贷后检查未做现场核查"才是根因——后者能改，前者不能。

### 2.1 5Why 终止条件（满足任一即停）

1. **该层已存在可执行的管理动作**（如"未做贷后现场检查"→ 可改流程）→ 停，取**最深层**可控点（治本，不是治标）
2. **完全不可控的外部因素**（宏观周期、行业政策突变）→ 停，标注"不可控·需组合对冲"
3. **追问 5 层仍未到可控点** → 标注「根因未明，需补充材料」，**不硬凑假根因**（硬凑比承认没查清危害大）

### 2.2 可控点取最深层

同一链条出现多个可控点时，取最深层：第 2 层可控点是直接原因（治标），第 3 层可控点是机制缺陷（治本）。"遇到第一个满足条件的就停"在归因里是错的——早停 = 挖浅了。

### 2.3 终止关键词覆盖真实表达

关键词表不能只写教科书表达（"未落实""缺失"），必须覆盖业务口语（"未到""没查""没看"），在真实数据上不断补充。

## 三、汇总级归因的三种拆解工具（10 个主题内化）

汇总级数据适合**可加分解**，慎下因果结论。因果表述以"行业研究结论 + 本行相关性观察"呈现并注明滞后期假设。

### 3.1 流量桥（Flow Bridge）——规模/余额变动归因

```
期末余额变动 = 新发放 − 正常到期偿还 − 提前还款 − 展期/续贷(不新增口径) − 核销与批量转让 − 重分类与口径调整
```

- 用于：规模"近零增长"、投放下滑、余额异常波动
- 汇报要点：把"需求不足 / 主动压降 / 口径变化 / 处置节奏"四类因素分开，避免把统计口径误读成市场萎缩
- 数据对应：新发放=凭证表 LN_DAT 落在区间；到期=MATU_DAT；提前还款=账单提前还款标识；核销=核销清收表

### 3.2 结构分解（Shift-Share）——结构迁移归因

```
总量变动 = 结构效应（各分项占比变化）+ 效率效应（分项自身增速）+ 交互项
```

- 用于：经营性与消费性背离、产业维度（种/养/林/渔/非农）、担保维度（信用/抵押/保证/农担）迁移
- 回答"增速下滑是结构走弱还是分项收缩主导"

### 3.3 平滑项暴露（Smoothing Exposure）——资产质量读数还原

```
真实不良生成 = 表观不良变动 + 核销 + 转让 + 收回 + 重组移出 − 期初
```

- **必须主动暴露平滑项**：展期、无还本续贷、核销、批量转让同时影响规模与不良读数
- 把资产质量结论建立在**不良生成率**而非表观不良率上；单列"重组贷款占比"作为解释项
- 灾害地区"不良读数偏低"可能是展期/无还本续贷缓释的结果，需主动说明，否则被误判为风险改善

### 3.4 传导滞后（Lag Transmission）——价格/政策/灾害传导

- 农业价格（生猪/猪粮比/粮价）对逾期率有 **2—4 个季度**滞后期；按"养殖/种植/非农经营"客群分组观察
- 政策切换（帮扶小额信贷）做**前后对比**：投放量/户均额度、利率与贴息、风险与补偿三分法
- 灾害冲击拆解：`受灾县域逾期上升 = 灾害直接冲击 − 农险理赔对冲 − 展期/续贷缓释 − 其他经营因素`

### 3.5 漏斗分析（Funnel）——授信用信转化

```
建档户数 → 授信户数 → 授信金额 → 用信户数 → 用信余额  逐层转化率
```

- 用于整村授信"有授信无用信"（用信率普遍 10%—30%）
- 按村/产品/客户经理维度定位堵点，结论指向"额度不匹配 / 利率偏高 / 需求不足 / 贷后顾虑"

## 四、证据链要求（报告可靠性的核心）

1. **每条成因必须给证据链**：现象 → 直接原因 → 管理根因 → 可干预点，每层标注 `[依据：…；来源：…（A/B/C/D级）]`
2. **证据与主张匹配**：C/D 级依据的结论标注「推定」，不进"立即执行"清单
3. **反证与例外**：说明结论是否存在不成立的特例（如引入担保机制后风险是否收敛）
4. **待确认项**：明确数据盲区，列出需补充的数据维度
5. **验证方式**：分组差异对比（不良组 vs 正常组）、切片稳健性（按机构/客群/产品分层）、时间切片验证

## 五、决策动作：四象限 + 6 字段

### 5.1 四象限（贡献度 × 可干预性）

| | 高可干预 | 低可干预 |
|---|---|---|
| **高贡献** | 立即整改（定人定时定 KPI） | 组合对冲（限额/分散/定价补偿） |
| **低贡献** | 例行优化（纳入常规流程） | 记录监控（只跟踪不投入） |

- 贡献度高但不可干预（行业下行）→ 组合对冲，不是"让客户经理去改"
- 贡献度低但可干预（缺复核岗）→ 照做，成本低收益确定
- **"不做什么"和"做什么"一样重要**：全部整改 = 都不整改

### 5.2 动作 6 字段（缺一不可，缺则标 incomplete）

`动作 / 责任岗 / 时限 / 验证指标 / 基线值 / 目标值`
- 基线值最容易被漏但最关键：无基线，"不良率降到 3%"无法判断是真改善还是大盘本来就在降
- 反例：「加强贷后管理」不是动作；「每月 15 日前完成现场检查并上传影像，覆盖率 100%」才是

## 六、口径纪律（三条）

1. **口径先固定**：农户贷款（含经营/消费）≠ 单户授信 500 万以下农户经营性贷款；跨年同比用可比口径。报告首页放口径说明。
2. **只做可加分解，慎下因果**：汇总级适合加法桥、结构分解；"价格下跌导致不良上升"以"行业结论+相关性观察"呈现。
3. **主动暴露平滑项**：固定附一张"重组与处置节奏表"，结论建立在不良生成率上。
